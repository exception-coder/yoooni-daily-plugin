# 开发日志 · 2026-08-23

## 08:32 · 新增 Skill · yoooni-ddl-sync

**原因：** 现有规则只要求首次 onboarding 和 Schema 迁移后人工重跑 DDL，Graphify 又只能解析已有文件，缺少从真实数据库持续刷新权威快照的安全执行链。直接用定时 Prompt 覆盖文件会混淆凭据、完整性校验、发布和调度职责，并可能用失败或缩量快照污染知识库。

**改动：**

- 新增 Oracle 元数据确定性导出器与 PowerShell 同步协调器。
- 新增 DPAPI 凭据、表数缩量门禁、内容哈希、生成区保护和原子发布规则。
- 新增稳定启动器和显式计划任务管理；插件安装与更新不得自动注册任务。
- 明确 Oracle Schema、DDL 快照和 Graphify 分别是权威源、审计快照和派生关系层。

**影响：**

- 团队可通过统一 Skill 手动检查或刷新 Yoooni DDL，并在用户明确要求后建立周任务。
- DDL 变化不会被自动提交或推送，仍需人工审阅。
- 新能力依赖 Windows DPAPI、Java 和可用的 Oracle JDBC 驱动。
